# UCG Assets

Vite + React + Tailwind demo for an Inventory Management UI following UCG aesthetic.

Quick start:

```bash
npm install
npm run dev
```

Files of interest:
- [src/mockData.js](src/mockData.js) - mock assets
- [src/components/Sidebar.jsx](src/components/Sidebar.jsx) - sidebar
- [src/components/SearchBar.jsx](src/components/SearchBar.jsx) - search input
- [src/components/AssetCard.jsx](src/components/AssetCard.jsx) - asset card
- [src/components/Dashboard.jsx](src/components/Dashboard.jsx) - grid
